Retained-Mode дерево сцены

Retained-Mode Scene Graph

Иерархическая DOM-структура с dirty-флагами. Рендерится только то, что изменилось. Никаких лишних перерасчётов лейаута на каждом кадре.

Hierarchical DOM structure with dirty-flags optimization. Recalculates only when geometry changes, eliminating CPU overhead.

📜

Песочница Lua 5.4

Sandboxed Lua 5.4 Scripting

Встроенный движок скриптов с изоляцией памяти, лимитом инструкций и таймерами (`ui.timer`, `ui.interval`). Безопасные хэндлы элементов исключают падения.

Embedded scripting runtime with memory isolation, instruction limits, and timers (`ui.timer`). Weak element handles prevent null-pointer CTDs.

🔄

Декларативный XML и Хот-релоад

Declarative XML & Hot-Reload

Создавайте интерфейс в XML файлах. Редактируйте стили и разметку прямо во время игры с мгновенным сохранением состояния без перезапуска Skyrim.

Declare layouts in human-readable XML. Tweak UI and stylesheets live in-game with instant state-preserving hot-reload.

MapCanvas и WorldAnchor

MapCanvas & 3D World Markers

Виджет радара / карты мира со слоями маркеров и компасом. `WorldAnchor` позволяет привязывать 2D/3D метки прямо к координатам и актерам в мире игры.

Native radar / world map widget with pinned markers. `WorldAnchor` projects 3D world positions and actors to screen space with edge clamping.

🗡️

Аппаратный курсор-меч

Hardware Nordic Sword Cursor

Оригинальный курсор Skyrim с мягкой тенью, рисующийся поверх всех меню. Не пропадает при переключении меню и не вызывает сбоев Flash/ActionScript.

Authentic Skyrim sword cursor rendered with smooth drop-shadow. Eliminates Flash cursor null-pointer dereferences and disappearances.

Локализация i18n из коробки

i18n Multilingual Localization

Автоматическая подстановка `$KEY` в разметке и скриптах. Из коробки понимает родные файлы локализации SKSE (`$KEY\tЗначение`), JSON и INI словари.

Automatic `$KEY` macro expansion in XML markup and Lua scripts. Native support for Skyrim SKSE translation files, JSON, and standard INI.

Как это работает

Code Showcase

Никаких сложных C++ цепочек инициализации — только чистая разметка и элегантные скрипты.

Zero boilerplate C++ initialization — clean declarative markup and expressive scripting.

<!-- Interface/PerfUI/HUD.xml -->
<UI script="HUD.lua">
  <Panel id="HealthBarRoot" width="320" height="32" bg="#000000aa" radius="6" padding="4">
    <ProgressBar id="HealthBar"
                 value="0.85" 
                 fill="#d9383a"
                 glossy="true"
                 label="$HUD_HEALTH" />
  </Panel>

  <WorldAnchor id="QuestMarker" target="actor:0x00014" clamp="true">
    <SvgImage src="marker_quest.svg" width="24" height="24" tint="#c9b27a" />
  </WorldAnchor>
</UI>
-- Interface/PerfUI/HUD.lua
local bar = ui.get("HealthBar")
local currentHp = 0.85

ui.interval(100, function()
    -- Плавное обновление шкалы здоровья
    bar:setProgress(currentHp)
    if currentHp < 0.25 then
        bar:setFillColor("#ff2222") -- Critical warning
    end
end)

-- Уведомление через нативную систему тостов
ui.toast(ui.tr("$QUEST_UPDATED"), 3.0)
// Clean Client C++20 API
#include <PerfUI/PerfUIApi.h>

void OnSKSEMessage(SKSE::MessagingInterface::Message* msg) {
    if (msg->type == SKSE::MessagingInterface::kDataLoaded) {
        auto* perfUI = PerfUI::Client::Get<IPerfUI_v3>();
        if (!perfUI) return;

        perfUI->RegisterOverlay("MyCombatOverlay", [](auto& ctx) {
            ctx.DrawText({100.0f, 50.0f}, "Combat Active", {255, 200, 80, 255});
        }, 10, false);
    }
}
