# MapCanvas Demo

Демонстрация виджета карты (`PerfUI::MapCanvas`) без Skyrim: игрок идёт по кругу, вокруг десять маркеров.

`MapDemoHud` получает данные через `PerfUI::VectorMapDataSource` — ровно тот же интерфейс, через который
в игру данные подаст мод. Меняется только источник значений: симуляция вместо движка.

## Где смотреть

Пример встроен в `PerfUI_Sandbox` (Win32 + DX11 + ImGui), открывается по **F9**.

```
xmake f -p windows -m debug --builddir="../.builds/PerfUI" -y && xmake build PerfUI_Sandbox
# либо CMake: cmake --build build --config Debug --target PerfUI_Sandbox
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `F9` | показать/скрыть демо |
| `M` | режим `Radar` ↔ `World` |
| `R` | `rotateWithPlayer` (карта вокруг игрока / север вверх) |
| `G` | сетка сторон света |
| `D` | подписи дистанций |
| `T` | перенести активную цель на следующий маркер |
| `+` / `−` | радиус радара ×1.5 / ÷1.5 |
| ЛКМ по маркеру или стрелке | сделать цель активной |

Строка состояния под радаром показывает режим, радиус, курс игрока, число спроецированных маркеров
и счётчик пересчётов `recomputeCount()` — видно, что при неизменных данных проекция считается один раз
за изменение, а не каждый кадр.

Что демонстрируется: маркер в центре, вращение карты вместе с курсом, пропорциональное расстояние,
стрелка на границе для дальней цели с подписью в метрах, подписи без наложений друг на друга.
Полное описание модели данных и координат — в `docs/MAPCANVAS.md`.
