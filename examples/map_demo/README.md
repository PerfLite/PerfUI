# MapCanvas Demo

Демонстрация виджета карты (`PerfUI::MapCanvas`) без Skyrim: игрок идёт по кругу, вокруг тринадцать маркеров.

`MapDemoHud` получает данные через `PerfUI::VectorMapDataSource` — ровно тот же интерфейс, через который
в игру данные подаст мод. Меняется только источник значений: симуляция вместо движка.

## Где смотреть

Пример встроен в `PerfUI_Sandbox` (Win32 + DX11 + ImGui), открывается по **F9**.

```
cmake -S . -B build && cmake --build build --config Debug --target PerfUI_Sandbox
build/Debug/PerfUI_Sandbox.exe
```

Песочница собирается только CMake (в `xmake.lua` она не объявлена); тесты и бенчмарк доступны
и там, и там.

## Управление

| Клавиша | Действие |
| --- | --- |
| `F9` | показать/скрыть демо |
| `M` | режим `Radar` ↔ `World` |
| `R` | `rotateWithPlayer` (карта вокруг игрока / север вверх) — только радар |
| `G` | сетка: лучи сторон света в радаре, адаптивная сетка с осями в мире |
| `D` | подписи дистанций |
| `T` | перенести активную цель на следующий маркер |
| `+` / `−` | радар: радиус обзора ×1.5 / ÷1.5 · мир: приблизить / отдалить |
| `C` | центрировать на игроке (в `World` включает и следование) |
| `F` | follow player вкл/выкл (`World`) |
| `←↑↓→` | двигать камеру (как правый стик: вверх = север) |
| колесо мыши | зум вокруг курсора (`World`) |
| перетаскивание ЛКМ | панель: карта едет за курсором (`World`) |
| ЛКМ по маркеру или стрелке | сделать цель активной |
| ЛКМ по значку кластера | навести камеру и приблизить (`World`) |
| ЛКМ по значку-мишени в углу | центрировать на игроке (`World`) |

Строка состояния под картой показывает режим, радиус (радар) или масштаб, шаг сетки и число
кластеров (мир), курс игрока, число спроецированных маркеров и счётчик пересчётов
`recomputeCount()` — видно, что при неизменных данных проекция считается один раз за изменение,
а не каждый кадр.

Что демонстрируется: маркер в центре, вращение карты вместе с курсом, пропорциональное расстояние,
стрелка на границе для дальней цели с подписью в метрах, подписи без наложений друг на друга,
камера с зумом вокруг курсора, кластеризация близких меток, линия «игрок → цель».
Полное описание модели данных и координат — в `docs/MAPCANVAS.md`.
